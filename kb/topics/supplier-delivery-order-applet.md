# Supplier Delivery Order applet

A supplier-access applet: a login linked to one or more supplier records creates and edits **internal outbound delivery orders** (the tenant's ordinary `INTERNAL_OUTBOUND_DELIVERY_ORDER`, short code OBDODR) with the supplier as the document entity, and registers the supplier's drivers as logins. Despite its name and its position under purchase-workflow it is not a purchase document: no stock, no journal, no link to PO or GRN.

## How it connects

- **internal-outbound-delivery-order-applet** — same table rows; FINAL, VOID, print and e-mail only happen there. Documents created here show up in its listing (Doc Short Code OBDODR) with `client_doc_type = SUPPLIER_DELIVERY_ORDER`.
- **driver-delivery-order-applet / delivery-driver-assignment** — Driver Listing here is the only place found that creates the supplier-driver login + driver-link pair; the Delivery Driver picker here is the only picker found that sets `delivery_driver_guid`.
- **supplier-login-access** — the same `entity_login_subject_link` + `is_supplier` filter drives the Purchase Order / GRN / Invoice Supplier Access applets (next in this lane's queue); compare their scoping code before documenting them.
- **knock-off-configuration** — `INTERNAL_SALES_ORDER → INTERNAL_OUTBOUND_DELIVERY_ORDER` shows the KO tab; `INTERNAL_OUTBOUND_DELIVERY_ORDER → INTERNAL_SALES_INVOICE` lets the Sales Invoice applet find FINAL delivery orders.
- **stock-availability** — open DO lines are `do_qty` (committed), never a stock movement.
