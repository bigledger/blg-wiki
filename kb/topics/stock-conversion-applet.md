# Stock Conversion

A stand-alone inventory document that turns one set of items into another at one location in a single FINAL: Input lines and Output lines on one header, each becoming a signed line in the stock ledger. It has its own tables and processors, no journal, and no link to the sales/purchase document engine.

## How it connects

- **stock-balance** — one ledger line per resolved item line; `server_doc_type` is the literal `Stock Conversion Applet`, not a `ServerDocTypes` enum value, so it is absent from the DCO signum sweep (25 types) and from any doc-type-keyed report filter that uses the enum.
- **stock-adjustment** — the generic-document alternative: quantity signum +1 with a per-line sign, a reason code and a journal; Stock Conversion has none of the last two.
- **moving-average-cost** — Input lines at zero `amount_txn` dilute MA; the Reset Moving Average Cost path is the correction.
- **serial-number-tracking** — serial create/delete follows the sign of `signum × base`; the panel enforces neither existence nor count.
- **internal-packing-order-applet** — the production-side kitting tool; the un-registered internal-kitting applet repo is a third candidate.
- **organisation-applet** — branch `MAIN_LOCATION` is both the Default Selection auto-fill and the backend fallback store.
- **inv-item-maintenance** — inventory links / PACKAGE ratios decide whether a line posts at all.
