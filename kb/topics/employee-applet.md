# Employee Maintenance (employeeApplet)

Employee master data: one entity record per employee (`bl_fi_mst_entity_hdr` with `is_employee`, entity type `EMPLOYEE` among a multi-select) with tabs for e-Invoice identity, Peppol config, addresses, contacts, remarks, categories, login link, payment config, tax, org-chart view, branch and company links, account-manager (customer) links, spending limits, report-to, approved leave (non-functional) and engagement-company access; plus Employee Category, Org Chart and File Import menus. Page rewritten to the applet-page standard in lane 4 run 6.

## How it connects

- **employee-login-invite** — Login tab invites by e-mail (or phone + TAC) with `add_user_to_tenant: true`, then links the login principal's subject guid; with INSTALL_ALL_APPLETS_ON_INVITE the chosen catalogs' applets are installed on registration.
- **org-chart** — Org Chart menu hidden by the mis-named `HIDE_CLAIMS`; the employee's Org Chart tab is a generated view of the charts they sit in.
- **claims** — Claim applet resolves the claimant from the login e-mail to this record ("Cannot find your email … from Employee Applet"); approvers from job title, branch links, org chart.
- **payroll** — nothing in this applet writes payroll tables; Payment Config writes `bl_fi_mst_entity_payment_method` (the run-5 note about `bl_pyrll_*` was wrong for this applet — those validators exist in the backend but are not called from here).
- **customer-maintenance / entity-master** — same table; File Import can convert an existing customer into an employee by matching on ID/tax number/e-mail/phone.
- **e-invoice** — E-Invoice tab fields (TIN, ID, SST, MSIC, address) and Peppol Config supply self-billed e-Invoice party data.
