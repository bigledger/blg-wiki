# Stock Balance

The quantity on hand for one inventory item at one location (and per company): the running total of the signed stock ledger `bl_inv_txn_line`, kept as the chain tip in `bl_inv_current_location_stock_balance` / `bl_inv_current_company_stock_balance`. Nothing types it in; only finalised documents whose server type has a non-zero quantity signum, stock conversions, production orders and stock reservations change it. The Stock Balance applet is the enquiry screen.

## How it connects

- **stock-availability** — reads `qty_ledger` and adds signed open-document quantities at query time; `qty_available` on the balance row is never written.
- **stock-report** — Historical Stock Balance = nightly HBAL snapshot of the current rows; Stock Summary by Location = ledger lines summed by date; they can differ after a backdate / void / refresh (gt#4807).
- **stock-take** — count report opening/closing from `bl_inv_txn_line`; never writes the balance; variance → stock-adjustment.
- **stock-adjustment** — quantity signum +1 with the line's Adjust-In/Out sign; the only user-facing correction path.
- **stock-transfer / customer-consignment / consignee-stock-transfer** — mirror lines on stock-in-transit / `guid_store_2`.
- **internal-purchase-grn-stock-in-applet / internal-purchase-invoice-no-stock-in-applet** — the +1 / 0 receiving pair; only the GRN Stock In reaches this ledger.
- **non-stock-and-trade-in** — separate ledger and unit tables; excluded from every inventory balance report (gt#1422 open).
- **moving-average-cost / fifo-costing** — cost columns on the same rows; backdated lines mark FIFO dirty and trigger reset-MA auto-create.
- **serial-number-tracking** — sub-balances processed per item sub-type after the row upsert.
- **90-ecomsync-related-applets** — marketplace `qty_available` derived from this balance minus open marketplace orders, written to `bl_mkp_entity_branch_stock_balance`.
