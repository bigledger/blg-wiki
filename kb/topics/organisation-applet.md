# Organization applet (Organisation Applet)

The master-data applet for companies, branches and locations, and the owner of the company-level switches that other applets never show but read at FINAL: the Knock Off Configuration (`bl_fi_comp_gendoc_flow_config`), the company e-Invoice / Peppol registration, tax defaults, timezone, branch main / delivery location, branch marketplace (EcomSync) rules. Also labels, groups, category groups and notification templates.

## How it connects

- **chart-of-accounts** — the company is created here and assigned a chart; its Default GL Codes, ledgers, fiscal years live there. `MISSING_DEFAULT_GL_CODE` is the failure both pages share.
- **blanket-purchase-order-applet / internal-consignment-purchase-order-applet / internal-consignment-grn-applet / internal-goods-delivery-note-applet / stock-requisition / stock-transfer** — every "downstream cannot find the source" case starts at the Knock Off Configuration owned here.
- **pos-general-applet** — cash-bill FINAL enforces the branch `location_guid`; branch rounding / group-discount items override the company ones.
- **e-invoice / my-e-invoice-admin-applet / mypeppol-admin-applet** — company `einvoice_status`, TIN/BRN/SST/MSIC, `einvoice_settings_json`, `peppol_status`, Peppol IDs are set here and consumed there; the forex posting-logic key has no UI (#5803).
- **bank-reconciliation / financial-reports** — company `default_timezone` drives date windows.
- **90-ecomsync-related-applets / cp-commerce** — the branch Marketplace tab is the EcomSync branch record.
- **membership-admin-applet / commission-scheme-applet** — `member_point_award_doc_in` / `member_point_in_doc_status` gate point awards; no UI.
- **budgetary-applet** — profit centres are not here (no screen in v3); `budgetary-applet` deliberately not added to `related_applets`.
- **consignee-stock-transfer / non-stock-and-trade-in / stock-take** — locations (class, SIT exclusion) are the dimension.
