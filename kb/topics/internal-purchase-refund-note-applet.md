# Purchase Refund Note Applet (Internal)

The purchase-side refund document. A copy of the receipt-voucher / sales-refund-note applet family (Revenue, Expense, Settlement, ARAP tabs; internal names still say "receipt voucher"). Since 2026-04-23 the backend treats it like a Purchase Return (quantity −1 / amount +1), but the applet still sends the old header signum, so creation fails on a backend that carries the change.

## How it connects

- **internal-purchase-return-applet** — same signums since April 2026; the working document for goods going back to a supplier.
- **internal-purchase-debit-note-applet** — same amount signum (+1), quantity 0; the non-stock alternative while this applet cannot create documents.
- **internal-sales-refund-note-applet** — the template this applet was copied from; its settlement lines are repaired to `INTERNAL_PAYMENT_VOUCHER`, this one's are not.
- **internal-payment-voucher-applet** — CASH_BACK settlement lines are stored as payment-voucher lines; contra partner for the supplier balance.
- **company-default-gl-codes** — CREDITOR / CREDITOR_NON_TRADE hard stop; PURCHASE, INPUT_TAX silently omitted.
- **e-invoice** — purchase allow-list member; self-billed type 14; VOID blocked while self-billed.
- **stock-balance** — Revenue-tab lines are outbound stock movements; `STOCK_BALANCE_OBJECT_NO_STOCK_AT_LOCATION` at FINAL.
