# Stock requisition (Requisition Out)

A branch's request for stock from another location: items, quantities, sending location, receiving location. The document records the request only — both signums are 0, so FINAL neither moves stock nor posts a journal. Fulfilment is a Transfer Out in the Stock Transfer applet, created either by that applet knocking the requisition off or by the requisition's CREATE ST button.

## How it connects

- **stock-transfer** — the Transfer Out is the fulfilment; two paths (knock-off from the transfer side needs the queue row; CREATE ST copies lines directly and updates the queue if it exists). After either, the requisition can no longer be reverted or voided.
- **knock-off-configuration** — two company rows govern the queues: GRN → Stock Requisition and Stock Requisition → Outbound Stock Transfer.
- **generic-document-approval** — the applet has the configuration screens; enforcement is absent for this document as of the read commit.
- **custom-field-placement** / **spreadsheet-view** — this applet is the reference implementation of both shared features (screen registry + per-tab column config); the same pattern is being copied to other applets.
- **stock-balance** / **stock-availability** — unaffected by the requisition; `SHOW_ITEM_STOCK_BALANCE` only shows balances while adding lines. A customer asked for min-stock quantities to appear here as well as in Stock Availability.
- **fiscal-period-lock** — applies to requisitions (not exempt), unlike stock transfers.
- **journal-posting** — signum-0 → `NO_JOURNAL_CREATED` job failure per FINAL, as for the Goods Delivery Note.
