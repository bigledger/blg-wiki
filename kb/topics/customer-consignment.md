# Customer Consignment

Two-document movement of stock you own to a customer's premises (a location of class CCSG) and back: Transfer Out (`INTERNAL_CUSTOMER_CONSIGNMENT_OUT`, qty −1) and Transfer Receive (`INTERNAL_CUSTOMER_CONSIGNMENT_IN`, qty +1), both amount signum 0, linked through an open queue. Stock ledger only; no journal.

## How it connects

- **consignee-stock-transfer** — creates the CCSG locations; posts the same OUT type through the same `createConsignmentTxns` mirror but as one document, no queue.
- **stock-transfer** — same UI template (`internal-{in,out}bound-stock-transfer` component names survive), but plain stock transfers use stock-in-transit and are exempt from the fiscal-lock check; consignment types are not.
- **stock-balance / stock-report** — the CSG clone is what makes the customer location's balance visible; Stock Summary by Location shows these as "Others".
- **permission-templates** — the LOCATION template is the only practical way to grant a user both the backend and the UI permission families.
- **generic-document-posting-status** — `validate_stock_balance` default true is a generic FINAL rule worth stating on every outbound-stock document page.
