# Creditor Report Applet (AP outstanding, aging, statements, historical, settlement reports, contra)

The Creditor Report Applet is the accounts-payable reporting front end: eight read-only reports over FINAL supplier documents (`bl_fi_generic_doc_hdr` with `arap_*` balances) and one write action, a contra between two open supplier documents. Settings are a handful of applet-local keys (aging period type, excluded document types, external-reference columns, print orientation, default branch, tab order, two default statement templates) stored in the applet's `APPLET_SETTINGS` JSON.

## How it connects

- **debtor-report-applet** — same code base with `AR_*` types; its V2 Field Settings has more keys (`ENABLE_DEFAULT_DATE_FROM`, `DEBTOR_EXCLUDE_SERVER_DOC_TYPES`, `USE_SALESMAN_CODE_INSTEAD_OF_NAME`, `ENABLE_BRANCH_FILTER_PERMISSION`, `HIDE_DOC_POPUP_COST_AMOUNT`, `HIDE_DOC_POPUP_GP`, `SHOW_CONTRA_DETAILREPORT_LAYOUT`) plus a Collection Invoice with Aging report.
- **debtor-and-creditor-report-applet** — separate applet, 15 menu items (both sides), same endpoints; the registry's documentation_url for the creditor applet wrongly points here (F-0042).
- **internal-payment-voucher-applet** — settlement lines and contras created there appear in Settlement tabs and the payment reports; contra created here changes the balances the PV applet offers for settlement.
- **internal-purchase-invoice-applet / grn / debit note / credit note / return** — the documents whose `arap_bal` is reported; only FINAL documents appear.
- **financial-report-applet / ledger-and-journal-applet** — reconciliation target; the recurring "does not tally with Balance Sheet" question comes from excluded doc types, non-FINAL documents, manual journals and forex conversion at document rate.
- **aging-period** — shared master (`bl_fi_aging_period_hdr/_line`) used by debtor, creditor and combined applets; selecting a period rewrites `AGING_PERIOD_TYPE`.
- **printable-format** — tenant-wide `bl_prt_printable_format_hdr`; statement templates are typed `STATEMENT_OF_ACCOUNT_*`, document PRINT uses the document-type templates.
- **historical-ageing** — `bl_fi_generic_doc_historical_ageing` snapshot behind both historical reports; maintained by the backend (`GenericDocumentHistoricalAgeingService`), recalculated on back-dated contras.
