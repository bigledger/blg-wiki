# Open questions

One file per question that lateral thinking raised and no source has answered.
`YYYY-MM-DD-<slug>.md` with: the question, which topics it came from, what was checked,
who could answer (role, not name), and `status: open | answered | wontfix`.
When answered, the answer goes into the topic note as a cited fact and this file gets
`status: answered` + a pointer.
