Bulk import lets you load hundreds or thousands of member records from a CSV file instead of creating them manually. A separate upload process handles bulk point transaction history when migrating from another system.

> [!WARNING]
> Always validate your CSV file against the template format before uploading. Errors in bulk imports are harder to undo than individual record mistakes — and customer records must exist first.

## Where to do this

Full step-by-step instructions, field explanations, and screenshots are in the applet guide:

**[Membership Admin Applet → Bulk Operations](/applets/membership/membership-admin-applet/#bulk-operations)**

- **[Upload Member Point Transaction](/applets/membership/membership-admin-applet/#upload-member-point-transaction)** — import historical point balances
- **[Bulk Import Checklist](/applets/membership/membership-admin-applet/#bulk-import-checklist)** — pre-flight checks before uploading
