A points currency is the virtual unit your members earn and redeem — like "Reward Points" or "Bonus Miles." You must create at least one currency before any earning or redemption can work. Most programs start with one currency and add more only when there is a specific business reason.

> [!TIP]
> Start with one currency. Multiple currencies add flexibility but also add member confusion and admin overhead. Add a second currency only if you need a distinct promotional type with different expiry or conversion rules.

## Where to do this

Point currencies are created and managed inside the **Membership Admin Applet** (under the **PTS CCY Module** sidebar menu).

Full step-by-step instructions, field explanations, and screenshots are in the applet guide:

**[Membership Admin Applet → Points Currency Management](/applets/membership/membership-admin-applet/#points-currency-management)**
