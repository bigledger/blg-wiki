A pricebook is a set of prices applied to a group of items for a specific audience. In a membership context, pricebooks are assigned to member classes — so a Gold member automatically sees Gold-tier prices when they shop. The pricebook method applies automatically at checkout when the member is identified; the cashier does not need to manually apply any discount.

> [!NOTE]
> Pricebooks are configured in Core, not in the Membership Admin Applet. The Membership module defines the class (who gets it). Core defines the pricebook (what the price is).

## Where to do this

**[Membership Admin Applet → Key Concepts](/applets/membership/membership-admin-applet/#key-concepts)** — understand how classes, pricebooks, and rewards connect

For the actual pricebook setup, refer to the Core pricebook documentation:
- Core → Pricebook Configuration — create the pricebook and assign items and prices
- Core → Member Class link — assign the pricebook to the correct member class
